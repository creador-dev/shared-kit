# AI skills

Reusable AI-agent skills and rules for frontend projects.

## Animation skills

The `animations/` collection includes equivalent integrations for:

- Claude Code: `.claude/skills/`
- Codex: `.codex/skills/`
- Cursor: `.cursor/skills/`
- Gemini and Antigravity: `.gemini/`
- Windsurf: `.windsurf/rules/`

Copy the directory for your preferred agent into a project's root. Keep each skill's supporting Markdown files beside its `SKILL.md` because the instructions reference them using relative paths.
